# Towing website concepts

Website design and development by **Aansh Bali**.
Portfolio and résumé: https://aanshbali.com/

Two independent, unofficial website concepts for Arrahien Towing Service in Modesto and SR1 Towing in Fort Bragg. They have not been commissioned or endorsed by either business.

Each concept includes a responsive layout, service sections, image gallery, attributed public review excerpt, business contact links, a Google map, and a website proposal with a Zoom-call invitation.

The proposal offers a one-time website build, with no monthly or annual service charges from Aansh. Domain registration and renewal are separate registrar charges. Paid hosting or additional services require separate agreement.

## Preview paths

- `arrahien/`
- `sr1/`

## Run locally

Serve this folder with a static web server, for example `python3 -m http.server 8000`.
